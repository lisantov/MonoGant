# ОСНОВНЫЕ ПОЛОЖЕНИЯ ДЛЯ РАБОТЫ ИИ-АГЕНТОВ

## КЛЮЧЕВЫЕ ОГРАНИЧЕНИЯ

1. Никаких серьёзных самостоятельных действий с Git. Нельзя, стэйджить файлы, создавать коммит, пушить, пуллить, мерджить, откатывать и т.п.
2. Нельзя добавлять никаких доп. библиотек в приложении без разрешния пользователя, только предлагать.
3. Изменения вносить можно только в файлы, которые касаются данного пользователем задания. Любые сторонние файлы изменять без прямого назначения нельзя
4. При изменениях обязательно пиши summary проделанной работы. Какие файлы были изменены, что было в них внесено и что в итоге получилось.
5. После любого изменения ОБЯЗАТЕЛЬНО прогоняй ESLint и Prettier, исправляй все ошибки, что они обнаружат и только после того, как они не покажут ошибок, можешь писать summary.
